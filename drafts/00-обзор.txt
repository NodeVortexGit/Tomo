ЧЕРНОВИ НА ПРОЕКТА TOMO — ОБЗОР
================================

За кого са тези чернови: за членовете на екипа, които искат бързо да се
ориентират в кода. Всеки файл в тази папка описва един модул (един .py файл
или една тясно свързана група файлове): за какво служи, как работи, какви са
основните му части, с кои модули е свързан, как се тества и на какво да се
внимава при промени.

Самият код е на английски (имена, коментари, документация в кода), а
черновите са на български.


1. КАКВО Е TOMO
---------------
Tomo е 3D персонаж (VRM модел), който живее върху работния плот на Windows и
Linux. Разговаря с потребителя (текст и глас, на английски и български),
помага с компютъра (команди в PowerShell/bash, приложения, звук, поглед към
екрана), разглежда снимките, които потребителят ѝ изпрати в чата, и има
здравна програма, която с камера следи упражнения.

Всичко работи на компютъра: езиковият модел е qwen3.5:9b в Ollama (или друг в
LM Studio), гласът е Piper — Dimitar на български, а на английски Alan или
Cori според това дали персонажът е мъжки или женски (решава моделът), —
разпознаването на речта е Vosk + Parakeet, камерата — MediaPipe.


2. ДВЕТЕ ПОЛОВИНИ: МОЗЪК И ТЯЛО
-------------------------------
МОЗЪК (папка tomo/) — работи в отделна нишка с asyncio:
  езиковият модел и инструментите му (ai.py), паметта (db.py), командите
  (commands.py), речта (speech.py, wake.py), снимките в чата
  (attachments.py), описанието на компютъра (sysinfo.py), здравната
  програма (health.py) и главният цикъл (brain.py).

ТЯЛО (папка tomo/body/) — работи в главната нишка:
  прозорецът (window.py), четенето на модела (vrm.py), скелетът
  (skeleton.py), изобразяването (renderer.py, mtoon.py, mtoon.glsl),
  физиката (movement.py), анимацията (animation.py), пружинните кости
  (springs.py), интерфейсът (ui.py, chat.py, workout.py, control.py) и
  главният цикъл на кадрите (app.py).

Двете половини НЕ споделят състояние. Те си разменят само съобщения,
описани в tomo/events.py:
  UiToBrain — от тялото към мозъка (напр. UserMessage, Shutdown);
  BrainToUi — от мозъка към тялото (напр. Chat, WalkTo, HealthLock).
Тялото изпразва опашката от мозъка веднъж на кадър, затова прозорецът никога
не чака модела.

ПОМОЩНИ ПРОЦЕСИ (папка scripts/) — отделни Python процеси, които мозъкът
пуска и с които говори с JSON редове през stdin/stdout:
  tts_piper.py (гласът), wake_word.py („Hey Tomo“), pose.py (камерата).
  setup_models.py изтегля моделите им (еднократно).

  5) 20-tomo.body.app  — главният цикъл на тялото

4. СТАРТИРАНЕ И ТЕСТОВЕ
----------------------
  uv venv --python 3.12
  uv pip install -r pyproject.toml --extra all --extra dev
  python scripts/setup_models.py     (моделите, еднократно)
  python -m tomo                      (приложението)
  python -m tomo ask "въпрос"         (само мозъкът, от терминала)
  python -m tomo ask --image снимка.jpg "въпрос"   (със снимка)
  python -m pytest -q                 (170 теста)

В Windows: .venv\Scripts\python -m tomo (или pythonw — без конзола).


5. КЪДЕ СА ДАННИТЕ
------------------
Папката с данни: %APPDATA%\tomo\tomo\data (Windows), ~/.local/share/tomo
(Linux). В нея: chroma/ (паметта), models/ и voices/ (моделите),
attachments/ (копията на изпратените в чата снимки),
health.json (графикът на упражненията), command-audit.log (всички команди),
tomo.log (журналът), tomo.lock (да работи само едно копие).
Настройките са във файла .env в папката на проекта (образец: .env.example).


6. РЕЧНИК
--------
VRM — формат за 3D персонажи (разширение на glTF): модел, скелет, изражения.
glTF / GLB — стандартен формат за 3D модели; .vrm е двоичен glTF (GLB).
MToon — „анимационното“ осветяване на VRM моделите (сенки, контури).
Пружинни кости (spring bones) — коса и дрехи, които се люлеят с движението.
Morph targets / blend shapes — изражения на лицето чрез изместване на върхове.
Tool use (инструменти) — моделът не само пише текст, а „извиква“ функции.
Ollama / LM Studio — програми, които изпълняват езиковия модел локално.
Цветови ключ (colour key) — в Windows чисто черното в прозореца е прозрачно.
ImGui — библиотека за интерфейс, рисуван всеки кадър (чатът, заключването).
ChromaDB — база данни с вектори; тук пази паметта на Tomo.
